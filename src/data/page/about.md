# 关于

## 我们是谁？

我们不是一个组织或团体，而是每一位热爱开放网络文化的独立博客创作者。我们致力于推动中文独立博客的生态建设。我们相信，博客不仅是一种表达方式，更是一种自由、真诚与独立的互联网精神。

我们共同提议并维护《中文独立博客创作契约》这一规范。

## 使命与职责

通过制定与传播《中文独立博客创作契约》，我们共同营造健康、可持续的创作环境。

- 制定与维护中文独立博客创作规范；
- 推动博客创作者之间的互助与协作；
- 促进开放内容与独立出版的发展；
- 维护网络表达的多样性与独立精神。
